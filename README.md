# Бот записи в салон — @AshotSimonyanBot

Клиент сканирует QR-код в салоне → открывается бот по deep link → выбирает услугу, мастера,
дату и время → запись сохраняется в Excel-файл на рабочем столе.

## Что умеет

- Запись по шагам: услуга → мастер (или «Любой свободный») → дата (14 дней) → время → имя → телефон → подтверждение.
- «Мои записи»: будущие записи клиента с кнопкой «Отменить».
- Напоминание клиенту за 2 часа до визита.
- Уведомления администратору о новых записях и отменах.
- Команды администратора: `/admin` — записи на сегодня и завтра, `/export` — прислать Excel-файл.
- `/help` — справка.
- Метка источника из QR-кода (`/start salon_1`) попадает в колонку «Источник».

## Настольное приложение

`./desktop.sh` (macOS/Linux), `desktop.command` (macOS, двойной щелчок в Finder) или `desktop.bat` (Windows).
Нужен собранный `target/salon-bot.jar` (`mvn package`).

- **Запустить / Остановить** бота — бот работает, пока открыто приложение. При закрытии окна бот останавливается.
- **Записи** — таблица с фильтрами (период, мастер, отменённые, поиск по имени/телефону/№), обновляется каждые 30 с.
  Двойной щелчок — подробности записи.
- **Новая запись** — для записи по телефону: свободное время считается так же, как в боте. Источник — «администратор»,
  напоминания по таким записям не отправляются (у клиента нет Telegram ID).
- **Отменить запись** — клиент из Telegram получает уведомление об отмене.
- **Лог бота** — вывод бота в реальном времени; полный лог в `logs/bot.log`, лог приложения — `logs/desktop.log`.

Не запускайте бота одновременно через приложение и `start.sh` — Telegram вернёт ошибку 409 Conflict
(приложение предупредит, если найдёт уже запущенный бот). Бот и приложение пишут в Excel по очереди
через lock-файл `.salon_bookings.xlsx.lock` рядом с таблицей.

## Требования

- Java 21+
- Maven 3.9+

## Настройка `.env`

Скопируйте `.env.example` в `.env` и заполните:

```
BOT_TOKEN=123456789:AA...          # токен от @BotFather
BOT_USERNAME=AshotSimonyanBot      # имя бота без @
EXCEL_PATH=                        # путь к xlsx; пусто — файл на рабочем столе
ADMIN_CHAT_ID=123456789            # ваш Telegram ID (узнать: @userinfobot)
TIMEZONE=Asia/Yerevan
API_ENABLED=                       # локальный REST API; пусто — включён, false — выключен
API_PORT=                          # порт API; пусто — 8787
API_TOKEN=                         # обязателен при включённом API: openssl rand -hex 32
```

Переменные окружения имеют приоритет над `.env`. Файл `.env` не попадает в git — не публикуйте токен.

## Где лежит Excel-файл

Если `EXCEL_PATH` не задан — `salon_bookings.xlsx` на рабочем столе текущего пользователя
(`~/Desktop`, а если такой папки нет — `~/OneDrive/Desktop`). Путь пишется в лог при запуске.

При первом запуске файл создаётся автоматически с листами:

| Лист | Колонки |
|---|---|
| Записи | ID, Дата создания, Клиент, Telegram ID, Username, Телефон, Услуга, Мастер, Дата, Время, Источник, Статус, Напоминание отправлено |
| Услуги | Название, Длительность (мин), Цена |
| Мастера | Имя, Рабочие дни (Пн,Вт,...), Начало, Конец, Активен (да/нет) |

Услуги и мастеров можно править прямо в Excel — бот перечитывает их не чаще раза в минуту.
Перед каждым изменением бот кладёт копию файла в папку `backups` рядом с ним (хранятся последние 20).

## Почему не держать файл открытым в Excel

Бот при каждой записи заново читает файл и заменяет его новой версией.

- **Windows:** Excel блокирует открытый файл. Бот повторит попытку 3 раза с паузой 2 секунды,
  затем вежливо извинится перед клиентом, а администратору придёт «закройте Excel-файл».
  Запись клиента в этот момент **не сохранится**.
- **macOS:** Excel файл не блокирует, но держит в памяти свою копию. Если вы потом нажмёте
  «Сохранить» в Excel, он **перезапишет** записи, которые бот добавил, пока файл был открыт.

Поэтому открывайте файл ненадолго и закрывайте после просмотра. Для просмотра безопаснее
команда `/export` — бот пришлёт копию в Telegram. Потерянные данные можно достать из `backups`.

## Сборка и запуск

```bash
mvn package
```

Запуск собранного jar (скрипт сам переходит в папку проекта, где лежит `.env`):

- macOS / Linux: `./start.sh`
- Windows: `start.bat` (двойной клик)

Или напрямую: `java -jar target/salon-bot.jar`.

Логи пишутся в консоль и в `logs/bot.log` (ротация: 10 МБ на файл, 30 дней, не более 500 МБ).

## Генерация QR-кода

```bash
mvn -q compile exec:java -Dexec.args="--source=salon_1 --out=qr_salon_1.png"
```

- `--source` — метка источника, попадёт в колонку «Источник» (латиница, цифры, `_`, `-`).
- `--out` — имя PNG-файла (по умолчанию `qr_<source>.png`).

Получится PNG 1000×1000 с QR-кодом ссылки `https://t.me/<BOT_USERNAME>?start=<source>`
и подписью «Отсканируйте, чтобы записаться». Для разных мест (стойка, зеркало, витрина)
делайте разные `source`, чтобы видеть, откуда приходят клиенты.

## Локальный REST API

Бот в том же процессе поднимает HTTP API для настольного приложения: `http://127.0.0.1:8787/api/v1`
(слушает **только** 127.0.0.1, порт — `API_PORT`). Выключается `API_ENABLED=false`.
Если API включён, а `API_TOKEN` пуст, бот не стартует и пишет, что нужно задать токен.

Все запросы, кроме `GET /api/v1/health`, требуют заголовок `Authorization: Bearer <API_TOKEN>`.
JSON в UTF-8, даты `2026-10-30`, время `14:30`, дата создания `2026-10-28T15:04`.

| Метод и путь | Что делает |
|---|---|
| `GET /health` | `{"status":"ok","timezone":..,"now":..}`, без токена |
| `GET /status` | состояние бота и хранилища |
| `GET /services`, `GET /masters` | услуги; активные мастера |
| `GET /bookings?date=&from=&to=&status=&q=&masterName=` | записи по фильтру, по дате и времени |
| `GET /bookings/{id}` | одна запись |
| `POST /bookings` | новая запись администратора (`clientName`, `phone`, `serviceName`, `masterName` или null — любой свободный, `date`, `time`) → 201 |
| `POST /bookings/{id}/cancel` | отмена; клиенту из Telegram уходит уведомление (заголовок `X-Client-Notified`) |
| `GET /slots?serviceName=&date=&masterName=` | свободное время |
| `GET /dates?serviceName=&masterName=&days=14` | рабочие даты (до 60 дней) |

Ошибки: `{"error":"код","message":"текст","fields":{...}}` — `unauthorized` 401, `validation` 400,
`not_found` 404, `slot_taken`/`already_cancelled` 409, `storage_busy` 503, `storage_error`/`internal` 500.
CORS разрешён для `http://localhost:5173` (dev), `null`, `file://`, `app://` (`API_CORS_ORIGINS` — через запятую).

```bash
curl -H "Authorization: Bearer $API_TOKEN" http://127.0.0.1:8787/api/v1/bookings?date=2026-10-30
```
